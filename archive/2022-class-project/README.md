# 2022 class project (original)

Project for **Survey Sampling (Muestreo), semester 2022-2**, Facultad de Ciencias, UNAM, in three parts.
Instructor: Dr. Gonzalo Pérez de la Cruz. Teaching assistants: Juan Andrés Cervantes and José Ángel Román.

**Team:** Daniel Franco Zárraga, Aaron Mauricio Gómez Jiménez and Jorge Sandoval Mendoza.

| File | Topics |
|---|---|
| `part1_probability_sampling_estimation.pdf` | Hansen–Hurwitz estimator, unbiased estimation under probability designs, complementary sampling, estimating a function of totals and its variance, sample size from a pilot sample |
| `part2_single_stage_designs.pdf` | Systematic sampling, unequal-probability sampling without replacement, Poisson sampling, comparison of single-stage designs |
| `part3_complex_designs_ine_2021.pdf` | Comparing three designs on the 2021 INE district results; two-stage sampling; the ENVI 2020 survey design |

These are the original documents, in Spanish. The analysis in the root of this repository is a
2026 re-implementation and extension of part 3 by Aaron Mauricio Gómez Jiménez.
